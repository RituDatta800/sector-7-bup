# GridWise LLM - Internal Test Console

Internal Next.js testing frontend for developer validation.

## Purpose

- Load sample 24-hour scenario JSON cases.
- Manually edit JSON requests and operator notes.
- Dispatch requests directly to the GridWise LLM backend service.
- View JSON results, solver hourly dispatch schedules, and summary metrics.
- Compare actual results against expected benchmark outputs.

## Getting Started

```bash
# Install dependencies
npm install

# Run the development server (runs on port 3001)
npm run dev
```

Open [http://localhost:3001](http://localhost:3001) in your browser.
